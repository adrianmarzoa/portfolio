# Portfolio

A single static portfolio with basic info, projects and skills.

## Stack

- HTML5 + CSS3 (no frameworks)
- Vanilla JS for the language toggle

## Sections

- **Header** : name, tagline and contact links (email, GitHub, LinkedIn), EN/ES language toggle.
- **About** : short bio.
- **Projects** : project cards with description, tech tags, feature list (with a "Pending" tag for work in progress) and links (code / live demo / technical decisions).
- **Skills** : grouped by category.

## Run

No dependencies or build process, just open the file:

```bash
git clone https://github.com/adrianmarzoa/portfolio.git
cd portfolio
```
Then open `index.html` in your browser.
